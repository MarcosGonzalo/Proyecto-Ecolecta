## Fase 1: Investigación Inicial

### 1. Control de versiones: Centralizado (SVN) vs. Distribuido (Git)
- **Centralizado (SVN):** Todo el historial vive en un único servidor central. Si el servidor cae, nadie puede guardar cambios ni ver el historial.
- **Distribuido (Git):** Cada desarrollador clona una copia completa del repositorio y su historial en su propia PC. Permite hacer *commits* y crear ramas sin conexión a internet.

### 2. Diferencia entre Git y GitHub
**Git** es la herramienta local de control de versiones instalada en nuestra computadora, mientras que **GitHub** es la plataforma en la nube donde alojamos esos repositorios para trabajar en equipo.
